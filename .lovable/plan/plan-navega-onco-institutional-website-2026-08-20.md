# Plan: Navega Onco Institutional Website

Building a premium, professional digital health website for oncology patient support.

## Visual Identity & Theme
- **Colors**: Elegant palette of light purple, lavender, white, and tech-blue.
- **Typography**: Clean, modern sans-serif (system defaults or specific pair if needed).
- **Design**: Rounded elements, soft shadows, plenty of white space, and smooth animations (Framer Motion).
- **Icons**: Lucide React for a modern, consistent look.

## Components to Build
1. **Header & Navigation**: Sticky navbar with logo and WhatsApp CTA.
2. **Hero Section**: High-impact messaging with professional imagery and dual CTAs.
3. **About Section**: Detailed explanation of mission and values.
4. **Pain Points & Solutions**: Visual cards addressing common patient difficulties.
5. **Services & Technology**: Showcasing navigation, telemonitoring, and individual plans.
6. **How it Works**: Step-by-step process for patient onboarding.
7. **Premium Programs**: Detailed cards for specific clinical offerings.
8. **Who We Serve**: Segmentation for patients, families, and healthcare providers.
9. **Team & Expertise**: Professional grid showcasing the specialists.
10. **Testimonials**: Interactive carousel for social proof.
11. **FAQ**: Expandable accordion for common questions.
12. **Blog Preview**: Placeholder for health articles and news.
13. **Final CTA & Footer**: High-conversion footer with floating WhatsApp button.

## Technical Details
- **Framework**: TanStack Start v1 (React 19, Vite 7).
- **Styling**: Tailwind CSS v4 using semantic design tokens.
- **Animations**: Framer Motion for entry animations and smooth transitions.
- **SEO**: Customized meta tags and semantic HTML structure.
- **Responsiveness**: Mobile-first design for all screens.

## Implementation Steps
1. Update global styles and theme variables.
2. Create reusable UI components (Buttons, Cards, Accordions).
3. Assemble the main landing page (`src/routes/index.tsx`).
4. Implement interactive elements (Carousel, FAQ, Floating Button).
5. Add SEO and final visual polish.
